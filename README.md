# 🎵 Music Player — Android App

A simple, clean Android music player built during my Software Development Internship at **CodeClause**. It lets users browse songs on their device, manage a personal song list, and play music with standard playback controls.

Built independently as the most complete of three assigned intern tasks.

---

## ✨ Features

- **Splash Screen** — branded launch screen with app logo and name
- **Song Library** — view all songs, add new tracks, delete existing ones
- **Player Screen** — full playback UI with album art, and:
  - ▶️ Play
  - ⏸️ Pause
  - ⏭️ Next
  - ⏮️ Previous

---

## 📱 Screens

| Screen | Description |
|---|---|
| Splash Screen | Displays app logo and name on launch |
| Song List | Browse, add, and delete songs from your library |
| Player | Playback controls with currently playing track's artwork |

## 🚀 Getting Started

### Prerequisites
- Android Studio (latest stable version)
- Android SDK
- A physical device or emulator running Android 7.0+

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/gauravsd-git/CodeClauseIntership_MusicPlayer.git
   ```
2. Open the project in Android Studio
3. Let Gradle sync and download dependencies
4. Run the app on an emulator or connected device
